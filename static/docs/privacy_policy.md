# ПОЛИТИКА КОНФИДЕНЦИАЛЬНОСТИ
**Сервис:** D&D Онлайн стол
**Версия:** 1.0 от 19.07.2026

## 1. Общие положения
1.1. Настоящая Политика определяет порядок обработки и защиты персональных данных Пользователей Сервиса «D&D Онлайн стол».<br>
1.2. Используя Сервис, вы даете согласие на обработку данных на условиях настоящей Политики.<br>
1.3. **Оператор данных:** Artem Cake (artem.cake@yandex.ru).<br>

## 2. Собираемая информация
2.1. При регистрации аккаунта Сервис собирает:
- **Имя пользователя (username)** — публичный идентификатор.
- **Адрес электронной почты (email)** — опционально, используется для связи.
- **Хеш пароля** — пароль хранится исключительно в виде хеша (argon2), исходный пароль не сохраняется.

2.2. В процессе использования Сервис собирает и хранит:
- **Игровой Контент:** созданные Пользователем миры, локации, лор-статьи, персонажи, кампании, домашние правила, настройки виртуального стола, сообщения в чате.
- **Логи действий:** события регистрации, входа в систему, применение миграций базы данных (без конфиденциального содержимого).
- **Техническую информацию:** IP-адрес, тип браузера, временные метки запросов.

2.3. Сервис **НЕ собирает и НЕ обрабатывает** данные банковских карт, платёжную информацию или иные финансовые сведения.

## 3. Цели обработки данных
3.1. Предоставление доступа к функционалу Сервиса (аутентификация, авторизация).<br>
3.2. Сохранение игрового прогресса, состояния виртуального стола и истории бросков кубиков.<br>
3.3. Обеспечение безопасности, предотвращение несанкционированного доступа и мошенничества.<br>
3.4. Улучшение качества работы Сервиса (анализ технических логов).<br>

## 4. Файлы Cookie
4.1. Сервис использует следующие категории cookie:
- **Обязательные (сессионные):** JWT-токен для аутентификации, лог-токен для служебных целей. Необходимы для работы Сервиса.
- **Функциональные:** `cookiesConsent` — запись факта принятия Политики конфиденциальности и использования cookie.

## 5. Передача данных третьим лицам
5.1. Сервис не передает персональные данные третьим лицам, за исключением случаев, прямо предусмотренных законодательством РФ.<br>
5.2. Сервис размещен на облачной платформе **Amvera Cloud**. Amvera не имеет доступа к содержимому базы данных Сервиса и выступает исключительно в роли поставщика инфраструктуры.<br>
5.3. Интеграции со сторонними платформами (Telegram, Discord и т.п.) на данный момент не реализованы.<br>

## 6. Безопасность данных
6.1. Пароли хешируются алгоритмом argon2.<br>
6.2. Аутентификация через краткосрочные JWT-токены.<br>
6.3. Межсерверное взаимодействие по HTTPS.<br>
6.4. База данных защищена от несанкционированного доступа.<br>
6.5. Администрация принимает разумные технические и организационные меры для защиты информации, однако не может гарантировать абсолютную безопасность данных, передаваемых через сеть Интернет.<br>

## 7. Хранение и удаление данных
7.1. Данные хранятся на протяжении всего срока существования учетной записи.<br>
7.2. Логи событий очищаются автоматически (настроена периодическая очистка старых записей).<br>
7.3. Пользователь вправе запросить удаление своего аккаунта и связанных данных, направив запрос на artem.cake@yandex.ru. Запрос обрабатывается в течение 30 календарных дней.<br>

## 8. Права пользователя
8.1. Пользователь имеет право:
- Получать информацию о хранящихся данных.
- Требовать исправления неточных данных.
- Отозвать согласие на обработку данных (влечет удаление аккаунта).
- Направлять жалобы и предложения.<br>
  8.2. Для реализации прав обращайтесь на artem.cake@yandex.ru.<br>

9.1. Администрация оставляет за собой право вносить изменения в настоящую Политику.<br>
9.2. Новая редакция вступает в силу с момента публикации в Сервисе.<br>
9.3. Продолжение использования Сервиса после изменений означает согласие с новой редакцией.<br>
